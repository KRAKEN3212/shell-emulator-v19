# Эмулятор командной оболочки ОС (вариант 19)

Графический (Tkinter) эмулятор командной строки UNIX-подобной ОС.

## Запуск

```sh
./run.sh        # Linux / macOS
run.bat         # Windows
```

## Тесты

```sh
python -m unittest discover -s tests -t .
```

## Этап 1. REPL

- заголовок окна: `Эмулятор - [username@hostname]` (данные реальной ОС);
- парсер с раскрытием переменных окружения (`$HOME`, `${USER}`),
  кавычками и экранированием;
- команды-заглушки `ls`, `cd` и команда `exit`.

## Этап 2. Конфигурация

Параметры командной строки:

| Параметр         | Описание                                  |
|------------------|-------------------------------------------|
| `--vfs PATH`     | путь к физическому расположению VFS       |
| `--script PATH`  | путь к стартовому скрипту эмулятора       |

При запуске выводятся отладочные значения всех параметров. Стартовый
скрипт поддерживает комментарии `#`; при выполнении на экране видны и
команды, и их вывод. Проверка параметров: `scripts/test_config.sh`
(`scripts\test_config.bat` в Windows).

## Этап 3. VFS

VFS загружается из JSON-файла (`--vfs`) и хранится только в памяти.
Двоичные файлы задаются в base64 (`"encoding": "base64"`). При ошибке
загрузки (файл не найден, неверный JSON, неверная структура) выводится
сообщение и используется пустая VFS. Служебная команда `vfs-info`
показывает источник VFS и число каталогов/файлов.

Примеры VFS лежат в `examples/vfs`, проверка — `scripts/test_vfs.sh`.

## Этап 4. Основные команды

| Команда | Описание |
|---------|----------|
| `ls [-l] [путь...]` | содержимое каталогов; `-l` — тип и размер |
| `cd [путь \| -]` | смена каталога; без аргументов — корень, `-` — предыдущий |
| `find [путь...] [-name ШАБЛОН] [-type f\|d]` | рекурсивный поиск |
| `rev ФАЙЛ...` | строки файлов задом наперёд |

Стартовый скрипт с примерами и ошибками: `examples/scripts/stage4_commands.txt`.
